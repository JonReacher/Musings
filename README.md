## How the site works

This repo is published with GitHub Pages at [jonragland.com](https://jonragland.com). The `index.html` at the root is the home page that links to each project, and every project folder is served at `jonragland.com/<folder-name>/`.

To add a project, put its folder in the repo with an `index.html` inside, then copy one of the cards in the root `index.html`.
